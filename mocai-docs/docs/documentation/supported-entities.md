# Supported Entities

This page is the entity index for the current Mocaí API.

Each entity now has its own focused page so the documentation stays simple to scan and easier to expand over time.

For the country-level context behind the currently implemented data, see [Brazil](../countries/brazil).

## Entity Pages

- [Person](./person)
- [Gender](./gender)
- [Address](./address)
- [Phone](./phone)
- [Company](./company)
- [CPF](./cpf)
- [Certificate](./certificate)
- [National ID](./national-id)
- [Voter Registration](./voter-registration)

## Quick Selection Guide

- Choose `Person` when you want a richer identity fixture with gender, age, and CPF.
- Choose `Address` or `Company` for business-domain records.
- Choose `CPF`, `National ID`, `Certificate`, or `Voter Registration` for document-focused tests.
- Choose `Phone` or `Gender` when you only need a smaller isolated value.
